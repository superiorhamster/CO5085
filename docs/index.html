IV. QUY ƯỚC TÁI LẬP KHOA HỌC & ARTIFACT CONTRACT

Đảm bảo tính toàn vẹn thực nghiệm (Reproducibility Protocol)

Tuân thủ nghiêm ngặt quy ước trong plans/00_conventions.md nhằm đảm bảo mọi kết quả trên trang web và báo cáo PDF hoàn toàn truy vết được.

🛡️ 1. Kiểm soát Ngẫu nhiên & Toàn vẹn Dữ liệu (SHA-256 Split Verification)

Tất cả thí nghiệm cố định seed = 42 cho Python, NumPy, PyTorch CPU/CUDA và bật cudnn.deterministic = True. Tập dữ liệu được chia phân tầng bằng StratifiedShuffleSplit(random_state=42) và lưu kèm mã băm SHA-256 của mảng chỉ số (fashion_mnist_split_seed42.npz, cifar100_split_seed42.npz, celeba_manifest_seed42.csv). Notebook lập tức dừng nếu phát hiện sai lệch hash.

💾 2. Atomic Checkpointing & Khôi phục Trạng thái RNG

Mỗi run lưu tại <output_root>/<assignment>/<run_mode>/<experiment_id>/ gồm config.json, environment.json, history.csv, metrics.json, predictions.npz cùng last.pt và best.pt. Checkpoint được ghi qua file tạm .tmp rồi thay thế nguyên tử (atomic replace) kèm toàn bộ trạng thái bộ sinh số ngẫu nhiên (rng_state) và StatefulRandomSampler (ở A2).

Quy trình đồng bộ kết quả từ GPU Runtime lên GitHub Pages

# 1. Sau khi chạy notebook với CONFIG["run_mode"] = "full" và tải thư mục artifacts/ về máy:
python3 tools/sync_site_data.py --artifacts-dir ./artifacts

# 2. Kiểm tra tính hợp lệ của toàn bộ Notebooks và GitHub Pages:
python3 tools/validate_notebooks.py
python3 tools/validate_site.py
